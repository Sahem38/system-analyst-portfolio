# Портфолио системного аналитика

Артефакты работы системного аналитика: требования, модели процессов и данных, архитектурные диаграммы, прототипы и проектная документация.

## Навигация

| Раздел | Что внутри | Нотации и форматы |
|---|---|---|
| [01 · Требования](01-requirements/) | Спецификации требований к ПО, варианты использования | SRS, Use Case (UML + спецификации) |
| [02 · Процессы](02-processes/) | Процесс записи к врачу «как есть» и «как будет», жизненный цикл записи | BPMN 2.0, UML State Machine |
| [03 · Проектирование системы](03-system-design/) | Архитектура микросервисов, межсервисное взаимодействие, потоки данных | C4 (контейнеры), UML Sequence, DFD |
| [04 · Данные](04-data/) | ER-модели, нормализация до 3НФ, логическая модель, словарь данных | ERD (Чен, Crow's Foot), 1НФ-3НФ |
| [05 · Прототипы](05-prototypes/) | Вайрфреймы и кликабельный прототип мобильных приложений, структура интерфейса | Low-fi / hi-fi, диаграмма структуры интерфейса |
| [06 · Документация](06-documentation/) | Задача на разработку, ПМИ, план тестирования, руководство пользователя | Постановка задачи с API, ПМИ, тест-кейсы |
